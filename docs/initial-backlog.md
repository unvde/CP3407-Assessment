# Initial Backlog Ideas

The following user stories represent the initial ideas for Reading Compass. They will be reviewed and refined after consultation with target users.

| No. | User Story | Priority |
|:---:|---|:---:|
| 01 | As a new reader, I want to create an account so that I can securely save and access my reading information. | 10 |
| 02 | As a reader, I want to add books to my personal reading list so that I can organise the books that interest me. | 10 |
| 03 | As a reader, I want to assign a reading status to each book so that I can distinguish between books I plan to read, am currently reading, have paused or have completed. | 10 |
| 04 | As a reader, I want to update my current reading progress so that I can track how much of a book I have completed. | 10 |
| 05 | As a reader, I want to create a reading plan with a target completion date so that I can manage my reading schedule. | 20 |
| 06 | As a reader, I want to view a dashboard summarising my active books and reading plans so that I can quickly understand my current progress. | 20 |
| 07 | As a reader, I want to search for books in my reading list by title or author so that I can quickly find a specific record. | 30 |
| 08 | As a reader, I want to filter my books by reading status so that I can focus on the books most relevant to me. | 30 |
| 09 | As a reader, I want to save notes while reading a book so that I can record important ideas and personal observations. | 40 |
| 10 | As a reader, I want to rate and reflect on a completed book so that I can preserve my opinion and learning for future reference. | 40 |
