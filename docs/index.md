# Reading Compass — Project Evidence

Reading Compass is a deployed community book-discovery application. This portal is the canonical entry point for CP3407 planning, implementation, testing and acceptance evidence.

## Final outcome

- Live application: https://reading-compass.onrender.com/
- Source repository: https://github.com/unvde/CP3407-Assessment
- Nine completed User Stories organised into three seven-day iterations
- Automated coverage for authentication, ownership, imports, discovery, reviews, lists, recommendations, forums, moderation and system journeys
- Render deployment with PostgreSQL, static-file handling and health checks

## Iteration summary

| Iteration | Product increment | Stories | Acceptance evidence |
| --- | --- | --- | --- |
| 1 | Secure account, shared catalogue import and private shelf | #1–#3 | `week5/user-stories/` |
| 2 | Category discovery, public reviews, lists and profiles | #4–#6 | `week7/user-stories/` |
| 3 | Forums, recommendations, moderation and production delivery | #7–#9 | `week9/` |
