## Status Rules

A story moves from **Todo** to **In Progress** when implementation begins.

A story moves to **Done** only when:

- Its required functionality is implemented.
- Relevant automated tests pass.
- The user can complete the intended workflow.
- Access-control requirements are satisfied.
- Acceptance criteria have been checked.
- Documentation has been updated where necessary.
