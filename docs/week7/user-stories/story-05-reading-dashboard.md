# Story 05 — Reading Dashboard

**Adjusted estimate:** 2 development-days  
**Final status:** done at Week 7 Day 4

As a reader, I want to view a personal dashboard so that I can quickly
understand my current reading activity.

## Acceptance Evidence

- The dashboard requires authentication.
- Its query is restricted to the signed-in reader and `Currently Reading` books.
- Each card shows available page progress and optional target information.
- Missing totals, missing targets and an empty dashboard have explicit states.
- Dashboard tests are documented as DASH-01–DASH-03 in the
  [Week 7 test cases](../test-cases.md).

The Week 7 Day 4 acceptance review found every criterion satisfied. Charts,
recommendations and reading-history analytics remain outside Iteration 2.
